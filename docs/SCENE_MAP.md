# RECOVERY 44 — Scene Map

구현 전 자료 검토 및 서사 설계. 2026년 1·2·3·5·6·7·8·9·10월 PDF 9개(총 193쪽), 기존 HTML 전체(12개 슬라이드, 내장 사진, 내비게이션·모달·카드 저장 JS)를 검토했다. 기존 시제품은 고정 520px 화면과 동일 사진/설명 패턴을 반복하므로 사실자료와 카드 생성 개념만 계승하고 새로 구성한다.

## 자료 판단

- 4월 PDF는 제공되지 않았다. 11·12월 활동과 연간 총성과를 추정하지 않는다.
- 8월 파일은 표지에 9월로 기재되어 있으나 본문 인사말·8월 사건으로 구분한다. 출처는 항상 **파일명 기준 월 / PDF 물리 페이지**이다.
- 풍천리: 3월 p19·27(100년 된 숲, 위협받는 111,999그루, 주민 투쟁), 5월 p8·24(감사 촉구·현장기도회), 7월 p5(7/4 공사 중단 요청), 8월 p10(8/5 위법성 미확인 설명·백지화 촉구). 일시 중단을 승리·백지화로 표현하지 않는다. 제안서의 2025년 날짜 오류는 인용하지 않는다. 잣 생산량 등 혼동 가능한 부가수치는 생략한다.
- 녹색교회: 5월 p16–19, 신규 16개·누적 162개 확인. 1월의 146개는 선정 전 수치이다.
- 환경주일 공식 주제는 5월 p3·9의 ‘칼을 쳐서 보습으로: 우리가 생명의 숲이 됩시다’. 6월 인사말의 변형 표현과 혼합하지 않는다.
- 919 행진: 9월 p2·4, 2만 명 초과·620개 시민사회단체. 참가자의 다양성과 예배→거리 흐름을 함께 표현한다.
- 네팔 탄소배출 수치는 9월 p11·10월 p22에 동일하게 제시됨. 독립 외부 검증 수치로 주장하지 않고 ‘활동보고서 인용, 2024년 기준’으로 표시한다. 피해·모금액·지원완료 성과를 만들지 않는다. 재난 현장 사진은 없으므로 모금 안내를 현장사진으로 둔갑시키지 않는다.
- 달력 사진은 실물 사진이 아니라 보고서 내 제작 안내 이미지로 명시한다.

## Design system

검정/깊은 숲(#08140f), 종이색(#f1eee4), 라임(#cefa73). 위협 장면은 먹색·사진 원색, 일상은 따뜻한 색, PART 05부터 종이색으로 전환. 초대형 영문 워드마크와 한국어 제목, 얇은 규칙선·작은 영문 위치표시를 사용한다. 데스크톱은 넓은 비대칭 사진과 타이포, 모바일은 세로 화면·44px 이상 터치 영역. 장면은 화면 단위로 이동하되 내용이 큰 경우 내부 세로 스크롤을 허용한다.

키보드 좌우·버튼·수평 swipe, 장별 목차와 뒤로 이동. 모달은 native dialog, 초점 복원. 모션 감소 시 전환·카운트업 즉시 완료. 사진은 로컬 WebP, 최초 1장 우선 로딩·나머지는 인접 장면만 로딩. 사진 오류 시 대체 배경과 설명을 표시한다. Canvas로 1080×1350 PNG를 생성하고 공유 불가 시 다운로드를 제공한다. 외부 프레임워크·추적·폰트 CDN 없이 실행한다.

## 사용자 후속 수정 반영

걷기기도회·탈핵순례 장면을 통합해 현재 25개 장면입니다. 기후행동 컨퍼런스 사진 현수막(5월 p4의 이미지 4·6·9)에서 2026.05.13, 서울YWCA 대강당, “기후위기, 신앙이 응답하다”를 확인했습니다. 초기 설계의 “날짜 미확인” 판단을 이 시각 자료로 보완했습니다. 풍천리는 8월 p10에 따라 7월 4일 중단 요청→8월 5일 위법성 미확인·매몰 비용 설명→백지화 요구를 본문에 연결합니다. 실제 공사 재개일·최종 사업 취소는 확인되지 않아 단정하지 않습니다. 출처를 드러내는 표현은 웹 화면에서 제거하고 이 문서와 데이터에만 보관합니다. 몽골·국제 컨퍼런스 사진은 해당 PDF의 실제 이미지로 확장했고, 네팔 비교는 모달, 달력 오른쪽 영역은 사진만 표시하도록 바꿨습니다.

## 추가 수정

“우리가 나무다 / 풍천리를 지키는 나무들” 독립 장면을 삭제해 현재 24개 장면입니다. 사용하지 않는 기존 장면 주소는 풍천리 설명 장면으로 안내합니다. 풍천리 후속 경과 끝에 연대·투쟁 다짐을 추가했습니다. 가덕도 원고적격 쟁점은 8월 p12를 근거로 부지 보상·주민의 소송 자격·각하 위험·절차상 유리한 결과·최종 승소와의 차이를 설명했습니다. 참여 버튼은 클릭 전부터 자동 맥박을 적용하고 이미 선택된 사진 탭은 선택 상태를 유지합니다.

## 2026-10-30 사용자 수정 반영

풍천리 문구를 ‘공사 중단 선언’, ‘공사를 중단하도록 했습니다’, ‘주민들을 서울로 부른’으로 변경했습니다. 수유동 버튼을 ‘기자회견’과 ‘수유동 숲지키기 예배’로 변경하고 기도회 문장을 수정했습니다. 산황산 버튼에는 10월 PDF p9의 이미지 1·0·2를 각각 연결했습니다. 교회별 기록은 6월 PDF p4(예닮)·p6(자연드림)·p10(순천승산)을 바탕으로 분리했고, 순천승산 사진도 p10 이미지 1로 교정했습니다. 이·취임식 이미지 2종은 PDF 자체가 512×341이며, 추가 손실 없이 저장하고 원본 비율로 표시합니다.
