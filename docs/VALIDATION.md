## 동의 후 완성 카드 Dropbox 전송 (2026-10-30)

사용자가 제공한 `https://recovery44-upload.kh3188.workers.dev/`에 `POST`하며, `FormData`에는 `file` 하나만 넣습니다. 파일은 원본 사진이 아닌 프레임·문구를 포함한 1080×1350 PNG입니다. 전송 이름은 ASCII로 만들고 임의 접미사를 붙였습니다. 사용자가 사진을 선택한 뒤 명시적으로 동의 체크 및 보내기를 눌러야 요청이 나갑니다. 생성/전송 상태, 중복 클릭 차단, 90초 응답 제한, ok true 성공 미리보기, API error/네트워크 실패의 안전한 텍스트 표시를 구현했습니다. Dropbox 인증정보를 클라이언트에 넣지 않고 쿠키·인증 헤더 없이 Worker에만 요청합니다.

입력은 image/*의 단일 파일이며 JPG/JPEG·PNG·WEBP·HEIC/HEIF와 15MB 제한을 안내·검사합니다. HEIC/HEIF의 기본 디코딩이 실패하면 로컬 heic-to 1.6.7로 변환합니다. 실제 HEIC 픽스처를 HEIC 및 HEIF 확장자/MIME로 읽고 변환기 함수가 로딩되는 것을 확인했습니다. 단일 HTML은 변환기를 data script로 포함해 외부 라이브러리 요청 없이 동작합니다. 라이브러리 라이선스 및 출처도 보관했습니다.

`tests/upload_check.py`: PC 1440×960·휴대폰 844×390·568×320·390×844·320×568, 분리 소스/단일 HTML의 10개 조건에서 모의 Worker로 검사합니다. 전송 URL·메서드, multipart boundary와 file 필드 1개, 파일명·PNG MIME·1080×1350 및 프레임 픽셀, 동의 전 전송 없음, 중복 방지, HTTP 200의 ok false/error 원문 표시(HTML 실행 안 됨), 네트워크 실패, ok true 미리보기, 15MB·형식 제한, HEIC/HEIF와 JPEG/PNG/WEBP, 인증 헤더 없음 및 단일 HTML의 추가 외부 파일 요청 없음을 확인합니다.

## 화면 정리·동의 팝업·동일 PNG 수동 재시도·Worker 파일명 (2026-10-30)
