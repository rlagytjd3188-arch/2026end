## 확인한 범위

- PC 1440×960, 모바일 세로 390×844, 작은 화면 320×568. 작은 화면은 reduced motion을 활성화합니다.
- 26개 장면 진입, 이전/다음, 각 장면의 상세 기록, 목차 점프, 해시 주소, 키보드 좌우·Space, 처음부터 다시 시작.
- 풍천리 나무 추가, 사건별 타임라인, 사진 전환·필름 가로 스크롤, 성찰/회심/행동 선택, 녹색교회 16→162 카운트업, 계절 순환, 몽골 연결, 네팔 배출량 비교 reveal, 행진 20,000+·620 카운트업, 회복 단어 선택.
- 4개 회복 유형별 다른 PNG 파일 생성과 실제 다운로드. 1080×1350 크기 검증.
- 이미지·데이터 요청 실패 UI 및 데이터 재시도.
- 화면 가로 넘침 여부, JavaScript 런타임 오류와 HTTP 오류.
- 추가 검사에서 Chromium의 터치 입력으로 실제 tap과 수평 swipe, 모달 Tab 초점 유지·Escape 닫기·초점 복원, Web Share 미지원 시 PNG 다운로드 대체 동작 확인.
- 단일 HTML 배포본을 HTTP로 제공해 HTML 이외의 추가 네트워크 요청 없이 실행·결과 카드 다운로드 확인.

## 검증 중 수정

카드 사진이 그라디언트 아래에 경계선으로 남는 문제를 Canvas clipping으로 수정했습니다. 모달의 유일한 버튼에서 Tab이 문서 바깥으로 빠지는 동작을 방지하고 초점을 열기 버튼으로 복원했습니다. 변형 애니메이션 장면이 내비게이션 클릭을 가리는 문제를 별도 메인 stacking context로 격리했습니다. 초기 진입 애니메이션이 끝나기 전 촬영되던 스크린샷은 전환 완료 후 촬영하도록 변경했습니다.

## 성능 관찰

개발 서버에서 초기 장면에 로딩한 리소스의 전송 크기 합계는 약 354KB입니다. 현재/다음 장면 사진, JS/CSS, 콘텐츠 JSON, 로컬 한글 폰트 2개를 포함합니다. 전체 사진·자료 이미지 34개는 약 2.1MB, 단일 HTML은 약 3.0MB입니다. 이는 용량 관찰이며 실기기 Lighthouse 성능 점수는 측정하지 않았습니다.

## 검증하지 않은 범위

- iOS Safari·Android Chrome 실기기, 실제 OS의 공유 시트와 사진 앱 저장 경로.
- 스크린리더 실사용 점검, 독립 자동 WCAG 전체 감사.
- 공개 호스팅·QR 코드·현장 네트워크. 배포와 GitHub push는 수행하지 않았습니다.
- 관리형 브라우저 정책이 `file://` 접근을 차단하므로, 파일 더블클릭 실행은 이 환경에서 직접 검증하지 못했습니다. 단일 HTML의 추가 리소스 요청이 없다는 것은 HTTP 제공 상태에서 확인했습니다.
- PDF의 수치에 대한 독립 외부 통계 검증. 출처 월·쪽과 자료 내 후속 경과를 대조했습니다.

4월 PDF는 제공되지 않았습니다. 11·12월 기록도 없어, 전체 연도의 성과를 추정하지 않고 제공된 10월까지의 기록으로 회고를 구성했습니다.
