## 검증 중 수정

카드 사진이 그라디언트 아래에 경계선으로 남는 문제를 Canvas clipping으로 수정했습니다. 모달의 유일한 버튼에서 Tab이 문서 바깥으로 빠지는 동작을 방지하고 초점을 열기 버튼으로 복원했습니다. 변형 애니메이션 장면이 내비게이션 클릭을 가리는 문제를 별도 메인 stacking context로 격리했습니다. 초기 진입 애니메이션이 끝나기 전 촬영되던 스크린샷은 전환 완료 후 촬영하도록 변경했습니다.
